# seibtribemarket

Seib Tribe Market — a Claude Code plugin marketplace of reusable skills.

## Use it

```bash
claude plugin marketplace add geseib/seibtribemarket
claude plugin install <name>@seibtribemarket --scope project
```

## Plugins

- **dynamodb-single-table** — Designs DynamoDB tables using single table design with generic keys, co-located entities, and GSI overloading.
- **nodejs-security** — Writes secure Node.js applications by default, applying OWASP Top 10 mitigations, input validation, and safe authentication.
- **csv-to-excel-report** — Generates styled Excel reports from CSV data, merging transactions with targets and calculating KPIs into a formatted .xlsx workbook.
- **context-audit** — Analyzes all Claude Code context sources for conflicts, overlapping skill triggers, and ambiguity.
- **pdlc** — Orchestrates a three-phase product development lifecycle workflow (Product, Architecture, Build) with human decision gates on local HTML pages.
- **speckit-specify** — Creates or updates a feature specification from a natural language feature description in a spec-kit project structure.
- **explain-code-spanish** — Explains code in both English and Spanish to support bilingual developer learning.
- **vote-overlay** — Adds a feature-flagged section-voting overlay to React sites: per-section voting with comments, JSON ballot export, and tallied results inline and in a summary panel.
- **eval-methodology** — Fair, reproducible skill evaluations across models and versions. Separates generation from grading, enforces complete coverage, and uses cost-aware tiebreaking.
- **eval-rebase** — Eval versioning and consistency enforcement. Tracks eval lineage so every score is traceable to the exact criteria, skill version, and model that produced it.
- **dashboard-management** — Auto-generated eval dashboard from JSONL results. Shows cross-model comparisons, version history, skill impact vs baseline, and cost-aware best-for-task rankings.
